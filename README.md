# Cape Squad

A comic-book animal platformer for the browser. Six caped heroes, each with a
different power, racing across four rooftops.

**Play:** https://mattjanineclark.github.io/cape-squad/

- **Panda** — Captain Bamboo — Roll (smashes crates, fits through vents)
- **Penguin** — Frostwing — Belly slide
- **Fox** — Ember Tail — Twin Leap (second jump)
- **Bat** — Night Shade — Glide
- **Frog** — Sticky Bolt — Wall cling and wall hop
- **Tortoise** — Iron Shell — Brief invulnerability

Keyboard: P1 `A`/`D` move, `W` jump, `S` power. P2 arrow keys.
Touch: move on the left, jump and power on the right. Two players share the
screen in landscape, one at each end.

Single self-contained HTML file, no dependencies. Every level was verified by
simulation to be finishable using only ordinary running and jumping, so no
hero's power is ever required.
